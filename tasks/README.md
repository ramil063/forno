# ТЗ по задачам

Один файл — одна задача. Номер в имени файла совпадает с номером задачи
в раскладке этапа, папка — с номером этапа: `tasks/stage-1/04-schema-warehouse.md`.

Зачем файлами, а не в чате: ТЗ приезжает в репозиторий вместе с кодом, и по истории
видно, что именно было задачей конкретного коммита, а не только «добавить миграцию».

Статусы: `запланирована` — ТЗ ещё не написано; `выдано` — задача в работе;
`готово` — коммит есть, задача закрыта.
